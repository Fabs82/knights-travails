knight_moves(start_coord, end_coord)
queue = [] hash_visited = {}
1. Aggiungi start_coord alla queue
2. Aggiungi a visited hash. hash_visited[start_coord] = nil (questo é il node iniziale)
3. while queue is not empty	
4. prendo il primo nodo nella queue e assegnalo. current =queue.shift	
5. trova le mosse valide a partire da current (no valori negativi o > 7).	
6. valid_moves.each |valid_move|		
7. controlla se é nell’hash		
8. Se é nell’hash, skip		
9. se non é nell’hash, registrala hash_visited[valid_move] =current		
10. controlla se valid_move == end_coord			
11. Se é == break the loop			
12. Ricostruisci il percorso passando da value a key fino a nil			
13. se non é == aggiungi valid_move alla queue			
14. repeat the loop
